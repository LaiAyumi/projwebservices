# API CRUD — Web Services em PHP

API REST em PHP puro (sem framework) para operações de CRUD, usando PDO para acesso ao banco de dados.

## ✨ Funcionalidades

- Endpoints de criação, leitura, atualização e remoção de registros
- Acesso a banco via PDO com prepared statements
- Separação entre camada de serviço e camada de modelo

## 🚀 Como rodar

1. Configure as credenciais do banco em `config.php`
2. Sirva a pasta com PHP embutido:

```bash
php -S localhost:8000
```
